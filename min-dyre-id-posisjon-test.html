🗺️ Se posisjonen på kart

SMS-knappen åpner bare telefonens meldingsapp med ferdig tekst. Du må selv velge mottaker og trykke Send. Kartlenken inneholder GPS-koordinatene.

🔒 Slik fungerer personvernet

GPS blir først forespurt når du trykker «Finn min posisjon». Nettleseren spør om tillatelse. Koordinatene vises kun på denne siden inntil du velger å åpne kart, SMS eller kopiere teksten. Du kan slette dem fra siden når som helst. Lukk siden for å avslutte testen.

Merk: GPS krever normalt HTTPS eller localhost. Å åpne HTML-filen direkte fra Nedlastinger kan derfor hindre posisjonstilgang på enkelte nettlesere. Test gjerne via GitHub Pages med HTTPS.
